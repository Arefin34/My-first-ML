Titanic ML Project

Predict survival of passengers on the Titanic using machine learning.

## Dataset
Kaggle Titanic Dataset: https://www.kaggle.com/c/titanic/data  
Download `train.csv` and `test.csv` and put them in a `data/` folder.

## Features Used
- Pclass, Sex, Age, SibSp, Parch, Fare, Embarked,  Name
- FamilySize, IsAlone, CabinDeck, TicketGroupSize

## Model
- RandomForest classifier
